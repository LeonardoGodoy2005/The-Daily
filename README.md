# The Daily 📰

**The Daily** é um portal de notícias responsivo desenvolvido com HTML5 e CSS3 como parte dos desafios práticos de desenvolvimento web da Rocketseat.

O projeto reúne notícias de diferentes categorias em uma única página, com navegação por seções e um layout adaptável a diferentes tamanhos de tela.

## ✨ Funcionalidades

- Navegação entre categorias de notícias.
- Seções dedicadas a diferentes temas.
- Cards com imagens, títulos e descrições.
- Layout responsivo para dispositivos móveis, tablets e desktops.
- Efeitos visuais e interações com CSS.
- Estrutura semântica com HTML5.

## 🛠️ Tecnologias

- HTML5
- CSS3
- Flexbox e CSS Grid
- Media Queries
- Git e GitHub

## 🎯 Objetivo

Praticar a construção de interfaces web, a organização de conteúdo editorial e a criação de layouts responsivos utilizando HTML e CSS.
